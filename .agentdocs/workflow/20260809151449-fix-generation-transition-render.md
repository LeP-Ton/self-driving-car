# 修复换代瞬间画布变黑并停止

## 背景与目标

- 1× 模拟速度在上一代达到最大帧数后，界面显示已进入下一代，但车辆、进度和神经网络画布全部停止。
- 5× 模拟速度在相同换代位置不会出现问题。

## 约束与原则

- 不改变适应度、遗传和停滞检测规则。
- 不使用延时掩盖问题，保证所有模拟速度在绘制前具有相同的车辆初始化状态。
- 保持动画循环每帧只进行一次绘制。

- [x] 根据右侧 Canvas 清空但未绘制定位到首次绘制异常。
- [x] 对比 1× 和 5× 在换代所在动画帧内的执行路径。
- [x] 在换代后、绘制前补充初始化模拟步。
- [x] 执行精确换代边界测试。

## 根因

- 1× 每个动画帧只执行一个模拟步。
- 当该模拟步结束上一代时，`startGeneration()` 创建了新车辆，但新车辆还没有执行过 `update()`。
- 随后的绘制读取尚未初始化的传感器、网络输入或碰撞多边形，异常会发生在下一次 `requestAnimationFrame()` 注册之前，因此动画永久停止。
- 5× 在同一个动画帧通常还有剩余模拟步，新种群会先完成初始化，所以未暴露该边界问题。

## 关键风险

- 补充的模拟步会使新一代在首次显示时已处于第 1 帧，这是有意的初始化行为。
- 如果未来将绘制与模拟拆为独立循环，应保留“不可绘制未初始化车辆”的约束。

## 当前进展

- 换代恰好发生在动画帧最后一个模拟步时，会在绘制前自动执行新一代第 1 个模拟步。
- 1×、5× 和 20× 现在共享相同的绘制前置条件。

## 测试用例

### TC-001 1× 最大帧换代边界

- 类型：回归测试
- 优先级：高
- 前置条件：模拟速度为 1×，第一代位于第 4999 帧。
- 操作步骤：执行一次完整的 `animate()`。
- 预期结果：自动进入第二代并完成第 1 个模拟步，车辆和神经网络成功绘制，下一动画帧已注册。
- 是否通过：通过。

### TC-002 高倍速换代回归

- 类型：回归测试
- 优先级：中
- 前置条件：模拟速度为 5× 或 20×。
- 操作步骤：运行至世代切换。
- 预期结果：不会重复初始化，不影响原有连续模拟行为。
- 是否通过：通过代码审查。
