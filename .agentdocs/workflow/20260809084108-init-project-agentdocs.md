# 初始化项目协作文档

## 背景与目标

- 项目根目录原先缺少 `AGENTS.md`、`CLAUDE.md` 与 `.agentdocs` 文档结构。
- 初始化协作规范，并记录项目结构及启动方式，方便后续会话快速定位信息。

## 约束与原则

- 不改动自动驾驶示例的业务代码。
- 仅新增协作与变更记录文档。
- 启动结论以各阶段实际存在的 `index.html` 和脚本引用方式为依据。

## 阶段与 TODO

- [x] 检查根目录文档及文件结构。
- [x] 确认各课程阶段是独立的原生 JavaScript 页面。
- [x] 创建协作规范、兼容入口、索引和本变更文档。

## 关键风险

- 直接以 `file://` 协议打开页面时，部分浏览器安全策略可能限制后续扩展功能；遇到此类问题应改用本地静态服务器。

- 初始化完成。
- 推荐运行第 10 阶段以体验功能最完整的版本。

## 代码变更

- `AGENTS.md`（新增）

```diff
+# 项目协作指南
+
+## 项目认知
+
+- 本项目是纯原生 JavaScript 编写的自动驾驶汽车课程示例，不依赖 npm 包或构建工具。
+- 根目录下的 `1. Car driving mechanics` 至 `10. Live stream variant` 是相互独立的课程阶段，每个目录均以 `index.html` 为入口。
+- 可以直接用浏览器打开阶段目录内的 `index.html`；为避免浏览器对本地文件的限制，也可以在根目录启动静态文件服务器。
+
+## 协作约定
+
+- 所有沟通、文档和代码注释使用中文；必要的英文专业名词首次出现时附中文说明。
+- 检索项目时先读取 `.agentdocs/index.md`，再按需读取其中指向的变更文档。
+- 每次代码变更都在 `.agentdocs/workflow/` 新建带时间前缀的 Markdown 文档，并同步更新 `.agentdocs/index.md`。
+- 重要变更需同步更新本文件中的项目认知。
+- 代码应重视可读性，并为不直观的逻辑补充中文注释。
```

## 测试用例

### TC-001 直接打开完整阶段页面

- 类型：冒烟测试
- 优先级：高
- 前置条件：已安装现代浏览器。
- 操作步骤：打开 `10. Live stream variant/index.html`。
- 预期结果：页面显示道路、车辆和神经网络画布，浏览器控制台无资源加载错误。
- 是否通过：待手动验证。

### TC-002 通过本地静态服务器访问

- 类型：冒烟测试
- 优先级：中
- 前置条件：已安装 Python 3。
- 操作步骤：在项目根目录执行 `python -m http.server 8000`，访问 `http://localhost:8000/10.%20Live%20stream%20variant/`。
- 预期结果：页面及全部 JavaScript、CSS 资源正常加载。
- 是否通过：待手动验证。
