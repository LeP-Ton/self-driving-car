# 修正最小速度 0 的语义

## 背景与目标

- 上一变更错误地将最小速度 0 解释为“关闭速度下限”，导致测试车仍可倒车。
- 按速度下限的正常语义修正：测试车最小速度为 0 时可以停车，但不能倒车。

## 约束与原则

- 测试车显式使用面板配置的 0～3 速度下限。
- 未显式传入配置的交通车继续使用原有的 `-maxSpeed / 2` 下限，不改变其行为。
- 不修改面板范围、下一代生效及持久化规则。

## 原行为说明

- 修改前，车辆速度统一限制为不低于 `-maxSpeed / 2`。
- 测试车的 `maxSpeed` 是 3，因此原最低速度为 -1.5，能够倒车。

## 当前进展

- 测试车配置 0 时，最终速度会被限制为不低于 0。
- 测试车配置正数时，最终速度会被限制为不低于该正数。
- 交通车未传入最小速度，仍使用 -1 的原有下限（交通车最大速度为 2）。
