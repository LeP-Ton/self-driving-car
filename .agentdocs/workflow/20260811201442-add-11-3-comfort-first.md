# 新增 11.3 舒适优先探索版本

## 背景与目标

- 在生存优先和距离优先之外，新增以乘员平顺体验为主要优化目标的自动世代训练版本。
- 安全仍高于舒适，避免早碰撞车辆因采样时间短而被误判为更舒适。
- 允许稳定跟车，不额外设置超车或最低进度门槛。

## 约束与原则

- 以 `11.2-distance-first` 为完整基线，保持交通、车辆物理、遗传流程和默认训练参数不变。
- 存活车辆按舒适成本优先、距离第二选择；全员碰撞时按距离优先、舒适第二选择。
- 舒适指标固定等权，不增加可调权重，保证不同训练结果可复现。
- 前 10 帧过滤最小速度从 0 跳到 2 的初始化冲击。
- 使用独立 localStorage（浏览器本地存储）键，不加载其他版本的大脑和历史。

## 舒适度定义

- 纵向加速度：`abs(速度变化) / 0.25`。
- 纵向冲击：`abs(本帧加速度 - 上帧加速度) / 0.4`。
- 横向加速度代理：`abs(速度 × 角度变化) / 0.09`。
- 转向突变：`abs(本帧角度变化 - 上帧角度变化) / 0.06`。
- 单帧舒适成本为以上四项的算术平均，各占 25%。
- 平均成本越低越好；面板舒适度为 `100 / (1 + 平均成本)`，越高越舒适。

- `main.js`：新增舒适成本采样、角度归一化和显示分数转换。

```diff
+function updateComfortState(car) {
+    const acceleration = car.speed - car.training.previousSpeed;
+    const angularVelocity = normalizeAngle(car.angle - car.training.previousAngle);
+
+    if (!car.damaged && generationTick > CONFIG.comfortWarmupTicks) {
+        const longitudinalAcceleration = Math.abs(acceleration)
+            / CONFIG.longitudinalAccelerationScale;
+        const longitudinalJerk = Math.abs(
+            acceleration - car.training.previousAcceleration
+        ) / CONFIG.longitudinalJerkScale;
+        const lateralAcceleration = Math.abs(car.speed * angularVelocity)
+            / CONFIG.lateralAccelerationScale;
+        const steeringJerk = Math.abs(
+            angularVelocity - car.training.previousAngularVelocity
+        ) / CONFIG.steeringJerkScale;
+        const frameComfortCost = (
+            longitudinalAcceleration
+            + longitudinalJerk
+            + lateralAcceleration
+            + steeringJerk
+        ) / 4;
+
+        car.training.comfortCostTotal += frameComfortCost;
+        car.training.comfortSamples++;
+        car.training.averageComfortCost = car.training.comfortCostTotal
+            / car.training.comfortSamples;
+        car.training.comfortScore = comfortCostToScore(
+            car.training.averageComfortCost
+        );
+    }
+
+    car.training.previousSpeed = car.speed;
+    car.training.previousAcceleration = acceleration;
+    car.training.previousAngle = car.angle;
+    car.training.previousAngularVelocity = angularVelocity;
+}
+
+function normalizeAngle(angle) {
+    return Math.atan2(Math.sin(angle), Math.cos(angle));
+}
+
+function comfortCostToScore(cost) {
+    return 100 / (1 + Math.max(0, cost));
+}
```
